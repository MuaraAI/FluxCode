FluxCode Live Share Relay

The shared relay behind Live Share in FluxCode.

Control
live.muaraai.com:7835
Tunnels
20000–20049
Slots
50 concurrent sessions
Encryption
ChaCha20-Poly1305, end to end

This relay only forwards encrypted bytes. The session key lives in the invite code and is never sent to the relay, so it cannot read the files, text, or cursor positions that pass through.

To start, open FluxCode → Live Share → Host, then send the invite code to your colleague over a private channel.
