Dirancang Khusus untuk Alur Kerja Pengembang

Semua yang kamu butuhkan sudah tertanam langsung tanpa perlu berburu puluhan ekstensi.

Rendering Native GPU

Ditulis dalam Rust menggunakan GPUI. Antarmuka digambar langsung oleh kartu grafis. Jendela tampil dalam 221 ms dan memori idle 1,4 MB, median dari 5 pengujian.

Panel Agen AI (ACP)

Mendukung protokol Agent Client Protocol: OpenCode 2, Claude Agent, Codex, GitHub Copilot, dan Mura. Tiga tingkat izin akses, undo per giliran, dan browser isolasi bawaan.

Live Share P2P Terenkripsi

Kolaborasi koding bersama secara real-time. Komputer host bertindak sebagai server dengan enkripsi ChaCha20-Poly1305 tanpa server perantara pihak ketiga.

Viewer Berkas Khusus

Membuka basis data SQLite (skema dan jumlah baris), dokumen PDF, arsip ZIP, dokumen Office, dan hex biner secara langsung dalam mode baca-saja.

Pintasan & Alur VS Code

Command Palette (Ctrl+Shift+P), Go to File (Ctrl+P), dan navigasi keyboard yang sudah kamu kenal. Tanpa perlu adaptasi ulang.

Nol Telemetri & Open Source

FluxCode tidak mengumpulkan data pribadi atau log aktivitas ketikanmu. Sepenuhnya transparan dengan lisensi GPL-3.0-or-later.
