An agent that asks first

Any ACP agent, installed in one click. Ctrl+L opens it.

  • OpenCode 2
  • Claude Agent
  • Codex
  • Gemini CLI
  • GitHub Copilot
  • Command Code
  • Asks before commands and edits
  • Undo per turn
  • Pick model, effort and mode
  • Its own browser, apart from yours
  • A full-screen workspace
  • Token saver and limit resume

  • WizTree disk map

    Instant Rust folder size analyzer with AI agent context.

  • Source Control

    Commit, push, PRs and Actions built in.

  • Non-text files

    Editable Bedrock NBT, plus SQLite, PDF, Office, ZIP and hex.

  • Multi-language terminal

    Clickable error cards and line jumps across languages.

  • Copilot inline

    Ghost text. Tab accepts.

  • VS Code Marketplace

    Search and install it all; 11 build kits built in.

  • VS Code keys

    Ctrl+P, Ctrl+Shift+P and the rest.

  • Six themes

    Glass panels, animated pixel backgrounds, three UI sizes.

  • One-click updates

    Every merge to main is a new build.

  • No telemetry

    The only automatic request is the update check.

  • Side bars, both sides

    Search, Git, Run or the agent, left or right.

  • Live search

    Results as you type, skipping what git ignores.
