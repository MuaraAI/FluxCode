FluxCode Development for Windows 10/11 (64-bit)

Install
  1. Extract this ZIP anywhere.
  2. Double-click Install.cmd. No admin rights needed.
  3. Open FluxCode from the Start Menu.

FluxCode is installed in %USERPROFILE%\.fluxcode\app and updates itself there:
when a new build is published, a card in the bottom-right corner offers it.

Uninstall: Settings > Apps > FluxCode Development > Uninstall.
Settings and the session stay in %APPDATA%\FluxCode-GPUI.

Without installing: FluxCode.exe also runs straight from this folder.
