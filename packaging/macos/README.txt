FluxCode Development for macOS 11 or newer (Apple silicon and Intel)

Install
  1. Open FluxCode-BuildDev-*-macos-universal.dmg.
  2. Drag FluxCode to Applications.
  3. Open FluxCode from Applications or Spotlight.

The first open: this build is not notarized by Apple yet, so macOS asks first.
  macOS 15 and newer: open FluxCode once, then System Settings > Privacy & Security >
  "FluxCode was blocked" > Open Anyway.
  macOS 14 and older: right-click FluxCode in Applications > Open > Open.
After that it opens like any app, and it updates itself: when a new build is published,
a card in the bottom-right corner offers it.

Uninstall: drag FluxCode from Applications to the Trash.
Settings and the session are in ~/.config/FluxCode-GPUI.
